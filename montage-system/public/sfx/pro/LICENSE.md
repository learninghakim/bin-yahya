# Signal "pro" SFX kit — sources & licenses

All files were trimmed around their hit point and loudness-normalised (EBU R128, −16 LUFS / −1.5 dBTP), mono 44.1 kHz.
`lead` in `src/styles/signal/sfx.ts` = seconds from file start to the hit, so a cue lands exactly on its word.
