# ستايل Signal — هوية مونتاج قابلة لإعادة الاستخدام

ستايل للريلز التعليمية التي يتكلم فيها شخص أمام الكاميرا. مبني بنفس **أسلوب** الريل المرجعي، لكن بهويته الخاصة:
- **الأسلوب المأخوذ من المرجع:**
  - لوحات واجهة داكنة فوق الصدر.
  - لحظات «مسرح» تغطي الشاشة كاملة.
  - كابشن أسفل الشاشة لكل كلمة.
  - boom منخفض عند تغيّر المشهد، ونغمات خفيفة عند ظهور العناصر.
- **الهوية الخاصة بـ Signal:** جرافيت داكن مع ليموني كهربائي (`#D4FF3A`)، وخط Readex Pro للواجهة، وخط Lalezar للكلمات الكبيرة.

المصادر:
- القواعد مأخوذة من مستودع [majedphotos/video-ad-editor](https://github.com/majedphotos/video-ad-editor) (رخصة MIT).
- الخطوط من نفس المستودع برخصة OFL (`public/fonts/signal/LICENSES.txt`).

## الملفات

| الملف | الدور |
|---|---|
| `tokens.ts` | **الهوية كلها:** الألوان والخطوط والمدد والمسافات. لتغيير البراند عدّل هذا الملف فقط |
| `clock.tsx` | التوقيت بالثواني المطلقة (`useNow`، `prog`، `enter`، `Grow`) |
| `SignalCaptions.tsx` | الكابشن السفلي: كل كلمة، في كبسولة، والكلمة المنطوقة بالليموني |
| `Panel.tsx` | لوحة الواجهة فوق الصدر، وفيها شارة حالة صغيرة أعلاها |
| `moments.tsx` | `HookCam` و`Burst` و`Stage` و`Slam` |
| `widgets/*` | محتوى اللوحات: `checklist` و`stepper` و`bars` و`reframe` و`links` و`follow` و`chips` و`iconTitle` |
| `sfx.ts` | قواعد الصوت التلقائية ومستوياتها |
| `SignalReel.tsx` | يحوّل `SignalSpec` إلى فيديو |
| `../../videos/signal/_demo.ts` | **معرض حي لكل عنصر.** في Studio افتح Signal ثم Signal-Gallery |

## القواعد

1. **الكابشن:**
   - يكتب كل كلمة تُنطق، في أسفل الشاشة (y≈1440)، ويبقى ظاهراً دائماً، حتى فوق اللوحات والمسرح.
   - يقسَّم إلى قطع قصيرة: 4 كلمات بالكثير، أو عند سكتة أطول من 0.45 ثانية، أو بعد علامة ترقيم.
   - الكلمة المنطوقة الآن بالليموني، وما قيل قبلها أبيض، والقادم باهت.
2. **مكان اللوحات:** على الصدر، بين y≈880 وy≈1380. لا تغطي الوجه، ولا تنزل على الكابشن.
3. **التوقيت:** كل عنصر يظهر لحظة نطق كلمته. والقيمة `to` تساوي آخر كلمة + 0.45 ثانية: يبقى العنصر قليلاً بعدها ثم يخرج خلال 0.4 ثانية.
4. **الحركة:**
   - الدخول يجمع ثلاثة أشياء معاً: شفافية، وصعود 22px، وإزالة تغبيش. التكبير يبدأ من 0.965 لا من الصفر.
   - لا ارتداد، ولا توهج على النص، ولا كتابة حرف بحرف للعربي.
5. **اللوحة تكبر مع محتواها:** الصف أو الشريط لا يحجز مكانه إلا قبيل ظهوره (`Grow`)، فلا تبقى اللوحة فارغة.
6. **الصوت:**
   - boom عند دخول المسرح وخروجه وعند الكلمة الضاربة (`slam`)، ونغمة خفيفة لكل عنصر يظهر، وtap عند ضغط الزر.
   - المستويات مقاسة على الريل المرجعي: الـ boom أعلى بحوالي 8 ديسيبل من الطبقة المنخفضة في الصوت، والنغمة أعلى بحوالي 11 ديسيبل من الصوت عند 2kHz.
7. **لا تعديل لوني على الشخص.** الهوية كلها في الرسوم.

## الرسوم المتحركة (`kind: "art"`) — الأساس في هذا الستايل

**القاعدة: الموشن يوصل الفكرة بالرسم، والكلام مكتوب في الكابشن.**
- لا نصوص كبيرة، ولا صناديق مليئة بالكلام.
- كل رسمة **تمثّل** معنى الجملة، وكل حركة فيها تقع على كلمة منطوقة.

الرسمة تطفو على الصدر فوق هالة داكنة ناعمة بلا إطار. أو توضع على شاشة كاملة (`stage: true`) مع عنوان قصير اختياري.
ولإضافة إطار الكاميرا وشارة REC استخدم `viewfinder: true`.

| `art.type` | يمثّل | المثال من فيديو Make It Stick |
|---|---|---|
| `gauge` | إحساس (سهل/صعب، مريح/متعب): إبرة تتأرجح | «مذاكرتك سهلة ومريحة» |
| `bolt` | صدمة: برق يُرسم وينفجر | «خلّني أصدمك» |
| `illusion` | وهم: شريط يمتلئ «فاهم ✓» ثم يتشوّش وينهار | «أكبر خدعة يخدعك فيها عقلك» |
| `book` | كتاب أو مصدر: ينفتح، ويظهر المؤلفون، ثم الشرائح | «الكتاب اسمه Make It Stick» |
| `curve` | الإحساس مقابل الواقع مع الوقت | «أضعف طريقة لتثبيت المعلومة على المدى البعيد» |
| `habits` | عادات خاطئة: ورقة يمر عليها قلم تظليل، وإعادة، وفقاعة تنكسر | «أظلّل وأعيد القراءة وأوهم نفسي» |
| `toggle` | تحوّل من «قبل» إلى «بعد» | «تغيّر كل شيء» |
| `journey` | خطوات أو طريقة: مسار يضيء محطة بعد محطة | «أقرأ، أغلق، أسترجع، أباعد، أخلط» |
| `barbell` | مجهود أو صعوبة مفيدة: أثقال تُرفع ودماغ ينعصر | «الصعوبة المفيدة… تعصر مخك» |
| `brain` | تعلّم أو روابط: دماغ تُبنى فيه شبكة، بعد شطب فكرة خاطئة | «مش ضعف… روابط عصبية قوية» |
| `follow` | CTA: زر متابعة يُضغط وجرس يهتز | «تابع الحساب» |

المعرض الحي لكل الرسوم في Studio: **Signal → Signal-Art** (الملف `src/videos/signal/_art.ts`).
وإذا احتاجت جملة فكرة لا توجد لها رسمة، **ابنِ رسمة جديدة** في `art.tsx` بنفس الأسلوب: SVG، وألوان الهوية، وتوقيت على الكلمات.

## أنواع اللحظات (`kind`)

| النوع | متى يُستخدم |
|---|---|
| `hookCam` | أول 2–3 ثوانٍ: إطار كاميرا وREC، وكلمات الهوك تقع على الصدر لحظة نطقها |
| `burst` | جملة صادمة: أيقونة تنفجر بأشعة وحلقات، ثم كلمة كبيرة |
| `stage` | فكرة محورية (اسم، قاعدة): شاشة كاملة داكنة، أيقونة وعنوان وشرائح. الكابشن يستمر تحتها |
| `slam` | انقلاب في القصة («تغيّر كل شيء»): كلمات ضخمة فوق الرأس |
| `panel` | لوحة على الصدر فيها عناصر واجهة (`widgets`). تُستخدم قليلاً، والأولوية لـ `art` |
| `art` | **الأساس:** رسمة متحركة توضّح الفكرة (الجدول أعلاه) |

## صناعة فيديو جديد بهذا الستايل

```bash
npm run fetch-raw <tag>
```
```bash
npm run transcribe <slug>
```
```bash
npm run new <slug> -- --signal
```

بعدها:
1. اكتب `src/videos/signal/<slug>.ts` من التفريغ `briefs/<slug>.transcript.txt` وتوقيتات `public/captions/<slug>.json`.
2. انسخ اللحظات التي تحتاجها من `_demo.ts`.
3. الفحص الآلي: `npm run check signal-<slug>`. يتحقق من:
   - كل توقيت يقع على كلمة منطوقة، وداخل نافذة مشهده.
   - قاعدة البقاء بعد آخر كلمة، والتداخل بين المشاهد، والزوم.
   - كثافة المؤثرات الصوتية، وسلامة الكابشن.
4. الفحص بالعين: `npm run still signal-<slug> <ثوانٍ…>` على منتصف كل مشهد ولحظات الانتقال.

**تزامن الكابشن:** whisper يضع بداية الكلمة التي تأتي بعد وقفة أبكر من نطقها بـ 0.15 إلى 0.3 ثانية.
- `npm run transcribe` يصحح ذلك تلقائياً، بنقل بداية كل كلمة إلى أول صوت مسموع.
- ولإعادة التصحيح يدوياً: `npm run snap <slug>`.

ولتغيير الهوية لعميل آخر عدّل `tokens.ts`: لون واحد مميز، وسطح داكن، وخطّان.
